# 引用作者字段约定

`replyToSender` 仍为现有加密消息 JSON 中的可选字符串，不改变数据库结构或中继协议。

- 新版 Android、Windows 和 macOS 的文本/媒体引用填入**被引用消息作者的 UUID**：引用自己的消息填自身 UUID，引用对方的消息填对方 UUID。不能填入 `Me`、`You` 或本地好友备注。
- 展示优先查找 `replyToId` 指向的本地原消息，并确认它属于当前会话，以原消息的 `isMine` 确定作者。这样旧版本保存的相对称谓也能正确展示。
- 本地原消息缺失时，只识别自身 UUID 或当前会话对方 UUID；其他值显示现有通用名称 `User`。不根据旧的任意昵称推断身份。
- 自己显示 `Me`；对方显示本机当前会话名称。该显示值不回写到存储或发送字段。
- Windows、Android、macOS 均在消息视图模型层解析作者；后端继续转发加密内容。

兼容范围：新版本可读取旧数据，无需迁移。未更新的旧客户端可能直接显示新字段中的 UUID，因此三个客户端应一起更新。原消息缺失时，旧记录中的昵称不能可靠恢复成作者 UUID，不做猜测。
