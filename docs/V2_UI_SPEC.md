# MsgAT V2 界面原型与规格

[打开三端交互原型](V2_UI_PROTOTYPE.html)。原型使用内置示例数据。顶部可选 Android、macOS、Windows、浅深主题、标准或窄窗，以及普通附件或读取失败示例。在第一条会话里向上滚动，再点「模拟收到消息」，即可观察历史位置和最新消息按钮。选择「打开附件后」的来电情景，再点「附件」，可以一边编辑说明，一边接听或拒接。原生实现与实际画面还需按 [三端参考记录](TELEGRAM_UI_RESEARCH.md) 逐项对照。

## 视觉基础

会话栏采用低对比度的冷灰绿表面，聊天阅读区用更浅或更深的连续底色。常态控件保持中性，MsgAT 原有绿色用在当前会话的细标记、主操作和已确认的回执。会话选中同时有底色、边线和位置标记。消息集中在有边界的阅读区，窗体边框、分栏、聊天顶栏和发送操作构成同一布局。背景采用纯色，附件本身提供内容重点。

| 角色 | 浅色原型 | 深色原型 | 用法 |
| --- | --- | --- | --- |
| 聊天底色 | `#F6F8F7` | `#171E1B` | 长时间阅读和消息之间的留白 |
| 顶栏、输入区、弹窗 | `#FFFFFF` | `#222B27` | 用细边线与聊天区区分 |
| 会话栏 | `#EDF2EF` | `#1C2521` | 让搜索、会话和选中项保持稳定的位置 |
| 主要文本 | `#172620` | `#E9F3EE` | 正文和名称 |
| 次要文本 | `#4E6159` | `#A9BDB3` | 时间、摘要、连接说明 |
| 强调 | `#126741` | `#8DDAB1` | 主要操作、焦点、确认图标 |
| 收到的文字气泡 | `#FFFFFF` | `#28332E` | 与阅读背景形成轻微明度差 |
| 发出的文字气泡 | `#DCEFE4` | `#204638` | 保留深浅模式下的正文、链接和回执层级 |

以上聊天底色、会话面、文字气泡和输入区已接入三端原生源码。macOS 与 Windows 保留原生列表选择，并加上选中位置标记。Windows 键盘焦点另显示轮廓，Android 保留单栏进入会话及原生点击反馈。尺寸、渲染和实际可访问性待统一客户端验收。

Windows 实机复测采用区分更明显的会话栏、阅读区和顶栏。浅色分别使用 `#DCE7E1`、`#EAF0ED`、`#FBFCFB`，深色分别使用 `#1E2C24`、`#18211C`、`#27342D`。切换主题时，已经打开的聊天、设置与输入控件应同步更新背景、正文、辅助信息和焦点轮廓。

Android 使用 Compose 的系统字体与 dp/sp，macOS 使用 SwiftUI/AppKit 的系统字体与 pt。Windows 的会话列表、文件夹、聊天顶栏和输入框使用 WinUI 3，消息时间线与对话框由 WPF 承载。两种 Windows 界面都按 DIP 布局，窗口随显示器 DPI 缩放。窄窗下，聊天顶栏将次要动作收入更多菜单，给联系人名称和状态留出空间。正文原型为 14，标题用更高字重，时间用等宽数字。三端沿用已有的聊天字号选项。中英文混排时，名称和摘要可以省略，时间、未读和必要动作各有独立空间。图标沿用各端现有资源，消息回执继续用灰色单勾、绿色单勾和绿色双勾，并为辅助功能提供对应的状态名称。

聊天顶栏在名字右侧显示联系人验证标记。三端读取已核对的安全码，并与当前联系人身份重新比对。切换会话、清除核对记录或对此联系人的信任状态变化时，重新读取验证状态。中继连接指示位于副标题，与在线和正在输入状态并列。

## 三端布局

| 平台 | 正常布局 | 约束与变化 |
| --- | --- | --- |
| Android | 会话与阅读为两层导航。聊天上方固定返回、联系资料和动作，底部固定输入区。附件使用系统安全区内的底部面板。 | 原型按约 400 和 340 dp 的阅读宽度预览。会话默认行高 72 dp，可用操作位保留 44 dp 空间。键盘或附件改变视口时，从最新阅读和历史阅读两种锚点恢复。 |
| macOS | 默认双栏。会话栏可拖动，原生标题栏和窗口行为沿用当前应用。 | 左栏沿用现有 260／300／460 pt 的最小、理想和最大宽度。原型以 68 pt 行高为起点。设置和附件窗口内容可滚动，操作区固定在底部。 |
| Windows | 默认双栏，连接状态、联系人、时间与会话操作各有明确位置。 | 左栏沿用 280／330／460 DIP，聊天列保留 390 DIP，窗口沿用 700 DIP 起点。原型以 62 DIP 行高为起点。窄窗时优先压缩摘要和合并低频动作，选择、未读数和发送入口保持可见。 |

## 首批流程

| 流程 | 正常路径 | 状态、焦点与恢复 |
| --- | --- | --- |
| 会话列表 | 搜索或点击会话，时间与未读位于同一右侧列。选中和未读单独显示。 | 空列表、搜索无结果和读取失败各显示相应反馈。切换并返回后恢复查询、选中和列表位置。窄窗下先压缩摘要。 |
| 聊天区 | 连续消息按既有规则组合，日期、未读与系统提示保留独立位置。文字按自然宽度排版，文件在消息内有类型、名称及状态。 | 读历史时保留消息 ID 和位置。停在最新处时才跟随追加。在已发送、已送达、已读状态变化时只更换回执。切换会话保存该会话的草稿及位置。 |
| 发送确认 | 选择、拖入或粘贴文件后进入确认。顶部显示目标会话，中部支持逐项预览、编辑、排序与重试，底部固定说明、批次选项和发送。 | 打开时桌面聚焦说明，输入法组合期间保持编辑。失败项保留在原位置。取消准备后回到同一选择和说明。修改过的批次需确认才能放弃，关闭后回到原会话的输入区域。 |
| 来电与当前任务 | 来电首先显示来电人、类型、接听和拒接。接通后显示连接状态、静音与挂断。桌面仍可使用原设置或发送确认窗口。 | 出现时保留原编辑焦点。使用接听或拒接控件时才进入来电操作。通话中若关闭原弹窗，继续在主界面保留当前通话状态。结束通话时回到仍有效的输入位置。原型覆盖来电、接听、重连、拒接和挂断。系统权限、音视频和来电通知由各端原生界面处理。 |

三端原生发送确认界面将附件和录音试听放在同一滚动区域，说明、发送选项和操作固定在下方。选项摘要可在空间不足时省略，取消与发送保留独立操作位。
加号菜单沿用确认页的表面和分隔色。安卓音频列表同时显示选中色和选入顺序，桌面菜单为键盘焦点保留轮廓。

三端通话界面把来电人和语音／视频状态放在主区，接听、拒接和挂断各有独立操作。收起后的浮窗同时显示头像、联系人、连接或时长及静音状态。macOS 与 Windows 另有非激活的来电窗口，用于设置或发送确认正打开时。小窗优先放在原窗口旁，空间不足时靠近当前屏幕顶部边缘。布局、焦点与屏幕缩放待统一客户端验收。

三端设置保留搜索条件，进入网络等子页再返回时保留设置列表的位置。隐私、通知和存储的正文可滚动，操作区固定。网络页对地址、端口及证书指纹显示中英文校验提示。存储页可重试用量读取。安卓头像裁剪及共用编辑器将顶部安全区交给工具栏处理，返回和确认位于系统状态栏及刘海下方，实际显示待同设备验收。

共享媒体沿用设置窗口的表面和分隔色。聊天预览与共享媒体共用加载和重试反馈，区别读取附件详情、校验本机附件和解码播放的状态。桌面的缩放、适合窗口和全屏控件按所选语言显示。Windows 播放器出错或正在准备时保留原生操作栏。预览关闭和定位原消息继续使用当前页的返回路径。

三端贴纸面板对分页加载和单张预览分别提供重试，保留已经显示的贴纸和当前筛选。预览返回后恢复原列表位置，导入候选用底色和勾选状态区分。真机验收还需覆盖动图、窄窗、搜索和发送后的焦点恢复。

搜索和置顶列表使用独立的结果区与操作区。打开前核对原消息；读取失败或原消息失效时在当前列表提示。日期和未读定位查询期间显示等待状态，查询无结果时保留日期或导航窗口。桌面日期查询移出界面线程，关闭窗口后舍弃迟到结果。

发送队列翻页或切换筛选读取失败时保留已显示结果，重试对应失败的页和筛选。macOS 队列的单条操作在窄窗可合并到菜单。三端的转发确认、转发队列和收藏使用单独的列表与底部操作区，接续现有的取消、重试和打开原消息入口。

草稿输入和回复／编辑条使用聊天主题色。回复／编辑条保留跳转到原消息和取消两个操作。链接预览开关和预览选项在同一区域，安卓在窄屏或系统大字下、macOS 在工具栏放不下时，把预览操作放进菜单。macOS 重试同一网址时根据新返回的封面重新解码。

三端首次设置和资料编辑在昵称下方提示长度超限，保存失败时保留昵称和所选照片。Android 和 macOS 的照片操作可换行。联系人名片的选择、资料状态、失败和重试均跟随界面语言。读取联系人或名片失败可以原位重试，原名片已失效时显示对应状态。

位置分享的坐标、时长和说明可滚动，取消与发送按钮固定在底部。安卓模式按钮允许换行，点击时长或静默发送的文字也可更改选项。打开位置详情时，读取失败可重试，已失效的位置在原页提示。

清空记录和删除联系人在三端显示目标会话名称和执行按钮，提交失败时保留当前界面并显示所选语言的提示。Windows 会话行支持右键、菜单键及 Shift＋F10，键盘打开的菜单贴着当前会话。桌面确认框保留 Esc 取消。

macOS 和 Windows 启动失败页用所选语言显示身份、加密资料库或启动服务相关提示，系统错误可展开查看。身份重置仍需从失败提示单独进入确认，存在待完成的重置时提示重新启动继续清理。安卓启动失败继续使用本地化的系统对话框。

三端通知页分开放置应用内开关和系统设置入口。安卓返回应用时刷新系统通知状态。macOS 重新成为前台时刷新权限和系统预览选项，并根据当前选项显示解锁后预览提示。Windows 可直接打开系统通知页，在应用内保存消息提醒和声音设置。

Windows 视频通话在收到远端画面前显示「等待视频」，联系人、当前通话状态及底部操作保留。远端画面开始后收起提示，视频轨道结束或暂停后恢复提示。本机画面继续在同一区域的角落显示。

## 动效原型参数

| 场景 | 参数 | 中断处理 |
| --- | --- | --- |
| 追加到最新消息 | Android 220 ms、macOS 210 ms、Windows 150 ms，淡入并轻微上移。 | 历史翻页、定位、回执更新即时更新。用户开始向上浏览时让阅读锚点优先。 |
| 附件确认出现 | 原型用 180 ms 的轻微位移及淡入。Android 以底边为起点，桌面以原生模态呈现为准。 | 关闭操作进入取消或放弃确认。读取完成时只更新尚在当前批次的条目。 |
| 键盘与系统减少动态效果 | 焦点通过轮廓表示。系统减少动态效果开启时即时更新状态。 | 恢复焦点以后保持原来的输入与滚动位置。 |

数值是基于现有主题和参考研究为原型选的起点，原生实机的帧序列仍待观察。原型内发送只形成示例待发送行。媒体预览、联系人、设置、通知、通话设备和原生视频窗口等仍按[逐屏研究范围](RECONSTRUCTION_PLAN.md#研究覆盖与制作前置条件)补全。正式验收覆盖浅深主题、长中文与英文混排、字体放大、Windows DPI、Android Insets、键盘与读屏，以及真实附件和来电条件。
